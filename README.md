# Kaspi Markup — прототип UI-улучшений

Живой демо-прототип трёх согласованных функций для платформы разметки данных
(speech-to-text). Не подключён к бэкенду — все данные фиктивные, цель —
показать поведение интерфейса, а не готовое решение.

Открыть: `index.html` в любом браузере, ничего устанавливать не нужно.

## Что показано

1. **Буфер слов с сохранением по проекту** — вкладка «Разметка». Слова
   хранятся в `localStorage` отдельно на каждый проект и не пропадают при
   обновлении страницы. Переключение проекта в выпадающем списке сразу
   меняет содержимое буфера.

2. **Точная настройка плеера** — шаг громкости и скорости 1% (ползунки),
   переключатель «общее на все аудио / для этого клипа» и трёхпозиционная
   кнопка повтора (`↻ выкл → ↻¹ повтор клипа → ↻∀ повтор всех аудио → выкл`).

3. **Аналитика WER/CER** — блоки дашборда можно перетаскивать мышью, порядок
   сохраняется. Внизу — таблица по сотрудникам со строкой «Среднее по
   проекту», которая считается автоматически, без ручного подсчёта.

## Техническая идея (для обсуждения с разработчиками)

Сейчас интерфейс разметки — встроенный UI Prodigy (Svelte-компоненты,
поставляются в собранном виде, кастомизация ограничена темой/CSS и набором
готовых «блоков»). Поэтому часть функций выше физически невозможно встроить
в текущий экран без форка чужого фронтенда.

Prodigy официально поддерживает работу через свой REST API — это открывает
путь без переписывания бэкенда:

- **Бэкенд остаётся Prodigy** — хранение датасетов, очередь задач, лицензия,
  существующая интеграция с загрузкой Excel не меняются.
- **Фронтенд — свой**, обращается к тем же эндпоинтам API вместо встроенного
  Svelte-приложения. В нём уже нет ограничений на буфер, ползунки, дашборд.
- Для показателей вроде «средний WER/CER по проекту» достаточно небольшого
  read-only сервиса, который агрегирует уже посчитанные данные — бэкенд
  разметки он не трогает.

### Поэтапный план

1. Быстрые улучшения в текущей архитектуре (то, что не упирается в Prodigy).
2. Свой фронтенд поверх REST API Prodigy — закрывает буфер, плеер, дашборд.
3. Полный уход от Prodigy — отдельное обсуждение, только если бизнес решит,
   что это оправдано.
