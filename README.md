# Kaspi Markup Platform — прототип

Однофайловый HTML-прототип платформы разметки аудио (`index.html`). Открывается
двойным кликом в любом браузере, без сборки и без сети — весь JS/CSS встроен
в файл. Не подключён к реальному бэкенду: логин, проекты и данные разметки —
демо-заглушки для показа интерфейса на встрече.

## Что внутри

- **Вход**: логин/пароль (любые непустые значения) или переход по QR
  (демо-код, автоматически «сканируется» через несколько секунд).
- **Список проектов**: таблица (Наименование / Задачи / Тип разметки /
  Организация / Роль / Дата создания / Статус / WER/CER) с поиском; кнопка
  «Перейти» открывает панель разметки для выбранного проекта.
- **Панель разметки**: плеер с волной, регулировка громкости и скорости
  с шагом 1% (скорость — в процентах, 50–200%), переключатель «этот клип /
  все клипы проекта» для громкости и скорости (сохраняется в `localStorage`
  по проекту), трёхпозиционная кнопка повтора (выкл → повтор клипа →
  повтор всех клипов проекта), буфер слов (Ctrl+Shift+1–9), приём/отклонение/
  пропуск записи, история принятых записей (только просмотр).
- **Аналитика проекта**: теперь привязана к текущему проекту, с переключателем
  проекта прямо в шапке (не выходя из аналитики). Настраиваемые блоки
  WER/CER — перетаскиваются мышью и скрываются/показываются через
  «Настроить блоки» (порядок и видимость сохраняются в `localStorage`),
  общий показатель качества, разбор ошибок, график скорости по дням, топ
  повторяющихся ошибок и таблица разметки по дням (Дата / Задач размечено /
  WER / CER / Время) — все цифры мокового проекта пересчитываются при
  переключении.
- Тема (светлая/тёмная/розовая), переключатель языка интерфейса (kz/ru/en/tr),
  окно горячих клавиш, тосты — без изменений.

## Что намеренно убрано из старого прототипа

- Вкладка «Найти и заменить» (CSV) и вкладка «Частые ошибки».
- Таймер усталости глаз и модальное окно с напоминанием о перерыве.
- «⚡ Инспектор правил» и панель «Правила (кратко)».
- Карточка «База КЗ» (поиск имён/локаций/брендов).
- Ряд кнопок быстрого перехода по сегментам аудио под волной (сама волна и
  метки сегментов на ней остались).
- Клик по истории для повторного открытия и редактирования принятой записи —
  история теперь только для просмотра.
- Индикатор «Автосохранение» и счётчик символов под транскрипцией.
- Поясняющие фразы-подсказки в интерфейсе и аналитике (в духе «это нужно,
  чтобы...») — оставлены только короткие подписи элементов.
